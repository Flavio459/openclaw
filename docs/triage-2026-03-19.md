# Change Triage - 2026-03-19

## Scope

This triage classifies the current `openclaw-push` worktree into:

- coherent feature work that should be reviewed as product code
- generated local artifacts that should stay out of version control
- structural risks that need a deliberate follow-up

## Executive Read

The current worktree is not random corruption.

It is a coherent cross-cutting initiative with three linked themes:

1. Collegium surface redesign in the UI.
2. Runtime and governance contracts behind those surfaces.
3. Model failover and telemetry propagation through chat/gateway flows.

The worktree is still large and should not be merged as a single opaque blob, but it no longer looks like "agent noise plus scattered edits".

## What Is Real Work

### 1. UI and product surface changes

The `ui/` changes form a connected feature set:

- new `home`, `portal-preview`, and `cockpit-preview` surfaces
- stronger navigation grouping
- explicit live-room continuation flow
- forum/praetorium/command reshaping around view-model adapters
- new `ui/src/ui/collegium/` contracts, adapters, fixtures, and tests

This is product work, not generated output.

### 2. Backend/runtime support

The `src/` changes also form a coherent set:

- fallback complexity and budget guard support in `src/agents/model-fallback.ts`
- subagent persona inheritance control in `src/agents/workspace.ts`
- model telemetry propagation into gateway chat payloads
- supporting tests around fallback, prompting, workspace, gateway, and agent events

This is implementation work attached to the UI/runtime initiative.

### 3. Policy and operating docs

The new files under `docs/model-policy/`, `config/policy/`, and Collegium docs are coherent with the same initiative.

They should be reviewed for correctness and overlap, but they are not junk.

## Risk Assessment

### High

- The branch mixes UI redesign, runtime semantics, gateway telemetry, docs, and policy in one batch.
- Review quality will be weak unless this is split or at least reviewed by domain block.

### Medium

- There is a strong naming/domain layer around Collegium, Forum, Praetorium, and Cockpit.
- That is coherent internally, but it raises the cost of review because behavior and language are changing at the same time.

### Medium

- The root workspace still references `openclaw-push` as a gitlink-like nested repo without `.gitmodules`.
- That is separate from this feature work, but still a structural risk.

## Professional Recommendation

Do not attempt broad rollback.

Do this instead:

1. Treat the current worktree as one initiative with multiple review blocks.
2. Review in this order:
   - `src/agents/` and `src/gateway/`
   - `ui/src/ui/collegium/` and `ui/src/ui/views/`
   - `docs/` and `config/policy/`
3. Keep generated artifacts ignored and out of the discussion.
4. Only after review, decide whether to split commits or keep as one feature branch.
